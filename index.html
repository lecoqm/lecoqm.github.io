01 / FORECASTING↗
A forecast is part of a system.01—03

Time series · ML engineering

Public repository

Bike demand
forecasting

An hourly prediction problem, extended into a reproducible ML workflow.

Train and track a demand model, serve predictions through an API, replay historical requests, and inspect monitoring reports. Compare a candidate against the current model on the same later hours, with promotion and rollback.

  • Python
  • scikit-learn
  • FastAPI
  • MLflow
View repository ↗
Read project notes

The problem

Predict hourly bike demand using public bike-sharing data. Respect time order when creating features and evaluating forecasts.

The implementation

Chronological training and evaluation, tracked experiments, an API, structured prediction logs, replay scenarios, and HTML monitoring reports.

What to inspect

The end-to-end demonstration and test suite in the repository show the path from a candidate model to replay, monitoring, promotion, and rollback.

02 / GRAPHS + LANGUAGE↗
Learning across representations.02—03

Graph learning · NLP

Team project

Molecular graph
captioning

Connecting molecular structure with natural-language descriptions.

A collaborative ALTEGRAD project exploring graph–text retrieval, retrieval-augmented generation, and direct graph-to-text generation. We worked across the approaches and compared their results.

  • PyTorch Geometric
  • GNNs
  • Contrastive learning
  • Language models
View my fork ↗

Shared work with Nazim Fadli and Zié Coulibaly. Original team repository ↗

Read project notes

The problem

Produce a natural-language description from a molecular graph. The task combines structural representations with language understanding and generation.

The approaches

Align graph and text embeddings for retrieval, use retrieved descriptions to support a language model, or condition a text decoder directly on a graph representation.

How we worked

Modelling, experimentation, and analysis were shared across the group. We contributed across the approaches, and the linked repositories present the collective project.

Coming soon

Industrial anomaly
detection

A public-data project inspired by my internship on industrial sensor time series.

The planned study will use a forecasting model and its residuals to detect unusual behaviour, with particular attention to adaptive thresholds that can absorb a sustained fault.

  • LSTM forecasting
  • Multivariate signals
  • Adaptive thresholds

↳ A standalone implementation with open data is planned. The public repository will be added here when it is ready.

Read the planned project outline

The question

How can an adaptive alert threshold detect sustained faults without gradually treating the abnormal behaviour as normal?

The planned comparison

A statistical baseline and an LSTM forecaster, with fixed and adaptive thresholds evaluated using the same saved forecasting residuals.

The planned evaluation

Use public industrial sensor data with fault labels. Report detected events, false alerts, and detection delay, with training and calibration separated from evaluation.
