Bike Demand Forecasting

Public project
Stack
Python, scikit-learn, FastAPI, MLflow, pytest
Focus
Hourly forecasting and the ML lifecycle
Links
Repository ↗

An hourly bike demand forecasting project with the tools to train, serve, replay, monitor, and compare models using public bike-sharing data.

Challenge

Make forecasting evaluation reflect how the model will be used: features must respect time order, and a candidate must be compared with the current model on identical later hours.

Implementation

  • Reproducible training: chronological splits, causal lag features, a baseline, and tracked experiments.
  • Prediction service: a FastAPI application with validation and structured prediction logs.
  • Replay and monitoring: historical requests, missing-history and invalid-request scenarios, and reports covering prediction errors and coverage.
  • Model management: candidate comparison, promotion, and rollback.

Results & deliverables

  • A complete demonstration that connects model comparison, replay, and monitoring.
  • HTML reports for inspecting forecasts, scenarios, and model comparisons.
  • Automated tests and CI, with setup and reproduction instructions in the repository.

Molecular Graph Captioning

Team project
Stack
PyTorch Geometric, GNNs, contrastive learning, language models
Focus
Molecular graphs to natural-language descriptions
Links
My fork ↗·Team repository ↗

A collaborative ALTEGRAD project investigating how to connect molecular structure with text. We explored retrieval, retrieval-augmented generation, and direct graph-to-text generation.

Team: Mathis Lecoq, Nazim Fadli, and Zié Coulibaly. We worked across the modelling approaches, experiments, and analysis.

Challenge

Generate a useful natural-language description from a graph representation of a molecule, and compare different ways of connecting structural and language representations.

Approaches

  • Graph–text retrieval: align graph and text embeddings using contrastive learning, then retrieve matching descriptions.
  • Retrieval-augmented generation: use retrieved descriptions to support a language model.
  • Direct generation: condition a text decoder on a graph representation.

Results & deliverables

The project compares these modelling strategies and documents the experiments and results in the repository. My fork presents the collective work and links back to the original team repository.

Industrial Anomaly Detection

Coming soon
Methods
LSTM forecasting, residuals, adaptive alert thresholds
Data
Public industrial sensor time series — dataset to be selected
Status
Public implementation planned

A future open-source project inspired by my internship on anomaly detection in industrial sensor data. It will use public data and a standalone implementation.

The question

How can an adaptive alert threshold detect a sustained fault without gradually absorbing the abnormal behaviour into its definition of normal?

Planned scope

  • Train a forecasting model on normal observations and derive anomaly scores from its residuals.
  • Compare fixed and adaptive thresholds using the same saved residuals.
  • Evaluate detected events, false alerts, and detection delay on labelled public data.

The repository and experimental results will be added here when the public project is ready.
